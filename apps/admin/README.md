# BarterDash Admin Web

React admin dashboard workspace for moderation and operations.

## Stack

- React + TypeScript + Vite
- shadcn-style component primitives + Tailwind CSS
- TanStack Query for server state
- Zustand for local app state
- Supabase Auth for login

## Scripts

```bash
npm run -w apps/admin dev
npm run -w apps/admin build
npm run -w apps/admin type-check
```

## Environment

Create `apps/admin/.env` from `.env.example` and fill values.
